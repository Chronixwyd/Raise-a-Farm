# Raise a Farm

A Roblox animal collection simulator.

## Structure
- `src/server` – server scripts (ServerScriptService/Server)
- `src/client` – client scripts (StarterPlayerScripts/Client)
- `src/shared` – shared modules (ReplicatedStorage/Shared)
- `assets` – non-code assets and references
- `docs` – design and technical documentation
- `default.project.json` – Rojo project file

## Setup
1. Clone the repo.
2. Install Rojo and run `rojo serve` in the project root.
3. In Roblox Studio, connect via the Rojo plugin.

## Status
Initial scaffold only. No gameplay systems yet.
